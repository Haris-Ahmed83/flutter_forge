# PDF Viewer 📄
> Effortlessly view PDF documents within your Flutter application.

## Description
Project #36: PDF Viewer is an intermediate-level Flutter application designed to demonstrate the integration and usage of PDF viewing capabilities. This project provides a clean and functional interface for opening and navigating through local PDF files, showcasing a common requirement in many mobile applications.

## Features
*   Seamlessly view PDF documents directly within the app.
*   Intuitive navigation for scrolling through pages.
*   Display of current page number and total pages.
*   Responsive user interface adaptable to various screen sizes.
*   Simple and clean design for a focused viewing experience.
*   Basic error handling for PDF loading issues.
*   Demonstrates effective use of a third-party PDF viewing package.

## Key Concepts Demonstrated
*   `flutter_pdfview`: Integration and utilization of the `flutter_pdfview` package for displaying PDF documents.

## Getting Started
To get a local copy up and running, follow these simple steps.

1.  Clone the repository:
    ```bash
    git clone https://github.com/Haris-Ahmed83/flutter_forge.git
    cd flutter_forge/projects/pdf_viewer # Adjust path if necessary
    ```
2.  Install Flutter dependencies:
    ```bash
    flutter pub get
    ```
3.  Run the application:
    ```bash
    flutter run
    ```
