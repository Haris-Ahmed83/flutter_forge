# Food Delivery App 🍔
> Order your favorite meals with ease and track your deliveries.

## Description
This Flutter project, "Food Delivery App" (Project #45), is an advanced application designed to simulate a complete food ordering experience. Users can browse a variety of restaurants and dishes, manage their selections in a cart, and place orders for delivery. It showcases best practices in multi-screen navigation and state management for complex user flows.

## Features
*   Browse a diverse menu of restaurants and food items.
*   View detailed information for each dish.
*   Add and remove items from a dynamic shopping cart.
*   Adjust quantities of items directly within the cart.
*   Proceed to checkout and place new orders.
*   View a history of past orders with their details.
*   User-friendly navigation across various app sections.

## Key Concepts Demonstrated
*   **Multi-screen:** Implements seamless navigation between different application screens such as the home screen, menu details, shopping cart, and order history, demonstrating efficient routing and state preservation.
*   **Cart:** Features a robust shopping cart system allowing users to add, remove, and update quantities of items before finalizing their purchase, complete with subtotal calculations.
*   **Orders:** Handles the entire order placement process, including confirmation, and provides a dedicated section for users to view and track their past orders.

## Getting Started
To run this project locally, ensure you have Flutter installed and set up.

1.  Clone this repository (or navigate to the project directory if part of a larger clone).
2.  Open your terminal in the project's root directory.
3.  Get project dependencies:
    ```bash
    flutter pub get
    ```
4.  Run the application:
    ```bash
    flutter run
    ```
