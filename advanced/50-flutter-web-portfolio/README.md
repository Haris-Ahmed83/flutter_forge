🚀 Flutter Web Portfolio
> A modern, responsive web portfolio crafted with Flutter to elegantly showcase your projects and skills.

## Description
This project is a personal web portfolio application developed using Flutter, designed to provide a sleek and interactive platform for showcasing one's professional work, skills, and experience. It leverages Flutter's capabilities to deliver a consistent and engaging user experience across various devices and screen sizes, making it an ideal template for developers and creatives.

## Features
*   **Responsive Layouts**: Adapts seamlessly to desktop, tablet, and mobile screens, ensuring an optimal viewing experience for all visitors.
*   **Dynamic Project Showcase**: Dedicated sections to highlight individual projects with detailed descriptions, images, and external links.
*   **Interactive UI Elements**: Utilizes smooth transitions and engaging animations to enhance user interaction and visual appeal.
*   **Skills & Experience Section**: Clearly outlines technical proficiencies, tools, and professional experience.
*   **Contact Information**: Provides easy ways for potential clients or employers to get in touch.
*   **Customizable Themes**: Designed with flexibility in mind, allowing for easy adaptation of color schemes and typography.
*   **Clean & Modular Codebase**: Structured for maintainability and scalability, following best practices for Flutter development.

## Key Concepts Demonstrated
*   **Responsive Design**: Achieved through the intelligent use of `MediaQuery`, `LayoutBuilder`, and flexible widgets like `Expanded` and `Flexible`, ensuring optimal layout and readability across all device sizes from mobile phones to large desktop displays.
*   **Animations**: Implemented using various Flutter animation techniques, including implicit animations (`AnimatedContainer`, `AnimatedOpacity`), explicit animations with `AnimationController`, `Hero` animations for shared element transitions, and custom `Tween`s to create smooth, engaging, and performant UI interactions.

## Getting Started
To get a local copy up and running, follow these simple steps.

1.  Clone the repository:
    ```bash
    git clone https://github.com/Haris-Ahmed83/flutter_web_portfolio.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd flutter_web_portfolio
    ```
3.  Install dependencies:
    ```bash
    flutter pub get
    ```
4.  Run the application (for web):
    ```bash
    flutter run -d web
    ```
    Or simply:
    ```bash
    flutter run
    ```
