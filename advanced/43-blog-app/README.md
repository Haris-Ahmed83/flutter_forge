# Blog App 📝
> A feature-rich blog application built with Flutter and Firebase.

## Description
Project #43 of the flutter_forge series, this Blog App demonstrates the creation of a dynamic content platform. Users can create, read, update, and delete blog posts, complete with rich text formatting for an enhanced writing experience. It serves as a comprehensive example for building data-driven applications with Flutter and Firebase.

## Features
*   User authentication (sign up, log in) with Firebase.
*   Create new blog posts with titles and rich text content.
*   View all published blog posts in a scrollable feed.
*   Edit existing blog posts, updating content and title.
*   Delete blog posts, with confirmation.
*   Integrated rich text editor for stylized post content (bold, italic, etc.).
*   Real-time data synchronization for posts using Firestore.

## Key Concepts Demonstrated
*   `Firebase CRUD`: Implementing Create, Read, Update, and Delete operations for blog posts using Firestore.
*   `Rich Text Editing`: Integrating and managing a rich text editor for user-generated content.

## Getting Started
To get a local copy up and running, follow these simple steps.

1.  Clone the repository:
    ```bash
    git clone [REPOSITORY_URL_FOR_THIS_PROJECT]
    cd blog_app # Replace with the actual project folder name
    ```
2.  Install Flutter dependencies:
    ```bash
    flutter pub get
    ```
3.  Run the application:
    ```bash
    flutter run
    ```
*Note: This project requires a Firebase setup. Please configure your `google-services.json` and `GoogleService-Info.plist` files and enable Firestore and Firebase Authentication (Email/Password provider) in your Firebase project.*
