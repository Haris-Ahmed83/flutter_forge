# Admin Dashboard Web 📊
> A modern, responsive web administration panel built with Flutter, showcasing advanced UI and data visualization.

## Description
This project, part of the `flutter_forge` series, demonstrates how to build a fully functional and responsive admin dashboard for web using Flutter. It exemplifies best practices for data visualization, tabular data display, and adaptive UI design across various screen sizes, providing a robust foundation for your next web administration panel.

## Features
*   Interactive data charts for visualizing key performance indicators and trends.
*   Dynamic and sortable data tables with pagination for efficient data management.
*   Fully responsive layout, seamlessly adapting to desktop, tablet, and mobile web views.
*   Intuitive sidebar navigation with expandable menus.
*   Clean, modular, and maintainable Flutter code architecture.
*   Integration of modern UI components for an enhanced user experience.
*   Optimized for web performance and smooth interactions.

## Key Concepts Demonstrated
*   **Charts:** Integration and display of various data visualization charts (e.g., line, bar, pie) using a suitable Flutter charting library.
*   **Tables:** Efficient rendering and management of large datasets within interactive, sortable, and paginated tables.
*   **Responsive:** Implementation of adaptive UI layouts using Flutter's `MediaQuery` and `LayoutBuilder` for optimal viewing on different screen sizes and devices.

## Getting Started
To get a local copy up and running, follow these simple steps:

1.  Clone the repository:
    ```bash
    git clone https://github.com/Haris-Ahmed83/flutter_forge.git
    cd flutter_forge/project_58_admin_dashboard_web # Navigate to this project's directory
    ```
2.  Install dependencies:
    ```bash
    flutter pub get
    ```
3.  Run the application on Chrome:
    ```bash
    flutter run -d chrome
    ```
